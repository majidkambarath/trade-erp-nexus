# Pre-demo checklist

## The day before

- [ ] Discovery done. You know which version (10 / 30 / 60) and which acts to stretch.
- [ ] You have rehearsed that version once, out loud.
- [ ] You have read [do-not-promise.md](do-not-promise.md) again. It changes with each release.

## Fifteen minutes before

- [ ] **Open the app now.** The demo server sleeps when nobody uses it and takes up to half a
      minute to wake. Wake it before the client is watching.
- [ ] Sign in to **your own** demo company (never the "golden" one; that is for recordings).
- [ ] Check it was rebuilt overnight: the dashboard shows this month, and the quotation to
      **Royal Feast Catering** is on Sales > Quotations, sent three days ago.
- [ ] Close email, WhatsApp desktop and anything else that can pop up a message on screen.
- [ ] Browser zoom 100% (110% if you are on a projector). Share the **browser window**, not the
      whole screen.
- [ ] Phone charged, Zarvia installed and signed in, for Act 6.
- [ ] *(60-minute version)* A private browser window signed in as **Ravi** (sales), for Act 5.
- [ ] A backup internet connection (your phone's hotspot).
- [ ] The do-not-promise list open on paper or a second screen.

## Within a day after

- [ ] Write down every question they asked that the [FAQ](faq-objections.md) did not answer.
      Send those to the product team.
- [ ] Send the follow-up: thank them, the three things they cared about in their words, the
      next step you agreed.
- [ ] If anything went wrong on screen, send the product team what you clicked and when.
